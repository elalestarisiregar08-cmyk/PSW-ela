Ai Use statements
Saya menggunakan Ai untuk membantu memahami kode dan menyelesaikan kendala selama pengerjaan website. Salah satu contohnya adalah memahami path gambar dan cara memeriksa file gambar melalui DevTools. Saya tetap memeriksa dan menguji hasilnya secara langsung untuk memastikan website berjalan dengan baik.

1. Navigasi Konten

Pengujian: Saya mengklik seluruh tautan yang ada di halaman index.html, daftar.html, dan kegiatan.html.

Hasil: Setiap tautan bisa diklik dan membawa saya ke halaman yang benar. Tombol Back berhasil mengembalikan saya ke halaman sebelumnya, dan tombol Forward membuka lagi halaman yang tadi saya tinggalkan.

2. Path dan Aset

Pengujian: Saya mengecek pemuatan gambar lewat tab Network di DevTools.

Hasil: Seluruh gambar termuat dengan baik berstatus 200, dan tidak ada error 404 yang muncul. Saya juga menyamakan penulisan huruf besar dan kecil pada nama file dengan file aslinya supaya gambar tetap tampil di perangkat mana pun. Selain itu, path gambar saya tulis secara relatif, tanpa alamat drive Windows, sehingga proyek mudah dipindahkan ke perangkat lain.

3. Audit Keseluruhan

Halaman yang diuji: index.html, daftar.html, dan kegiatan.html.

Pengujian: Saya mencoba mengoperasikan situs dengan keyboard, melihat tampilannya pada lebar layar 320px dan 1200px, serta memperbesar tampilan dengan zoom.

Hasil: Perpindahan antar elemen dengan tombol Tab berjalan lancar. Tata letak situs dapat menyesuaikan diri di lebar 320px maupun 1200px. Ketika di-zoom, teks dan layout ikut menyesuaikan sehingga isi halaman tetap nyaman dibaca.

4. Validasi HTML

Pengujian: Saya memeriksa seluruh file HTML dengan HTML Validator.

Hasil: Semua file lolos validasi dan tidak ada error yang ditampilkan.
