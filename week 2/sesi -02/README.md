Debugging
Pada tahap ini dilakukan pengujian terhadap CSS dan JavaScript pada website. Pertama, dilakukan pengecekan file CSS melalui Developer Tools. Awalnya terdapat kesalahan pada path CSS sehingga muncul status 404, yang berarti file tidak ditemukan. Setelah path diperbaiki sesuai dengan lokasi file yang benar, CSS berhasil dimuat dengan status 200.

Selanjutnya dilakukan pengujian pada tombol “Tampilkan salam”. Pada awalnya tombol tidak berfungsi karena terdapat kesalahan pada script atau selector JavaScript. Setelah diperbaiki dan disesuaikan dengan elemen pada HTML, tombol dapat bekerja dengan baik dan menampilkan salam sesuai fungsi yang dibuat.
